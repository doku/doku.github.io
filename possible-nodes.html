See the Future Before You Step Into It

URL: https://future.jasonwang.us
Stack: Python FastAPI

What It Is

You’re about to make a decision. Maybe it’s a job change. Maybe it’s moving cities. Maybe it’s something smaller but still important. You can guess what happens next. Or you can see it. This is a system for modeling causal relationships and exploring “what if” scenarios before you commit.

What It Does

  • Map out your options — lay out each choice and see what branches from it
  • Follow each path — the system shows likely outcomes, dead ends, and unexpected connections
  • Simulate decisions — it’s like a flight simulator for your life choices
  • Stop hoping — see where each path leads before you take the first step

How It Works

You build a directed acyclic graph of your decisions — each node is a choice or event, each edge is a causal link. You pick a starting point and follow the graph forward. The system shows you what happens downstream from each choice, so you can compare paths before committing to any one of them.
