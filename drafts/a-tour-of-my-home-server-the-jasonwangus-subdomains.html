A Tour of My Home Server: The jasonwang.us Subdomains

Over the past few years, I’ve been running a Raspberry Pi 4 at home that hosts a growing collection of web services. Each one lives under its own subdomain of jasonwang.us, proxied through nginx with SSL via Let’s Encrypt. Here’s a guided tour of what’s running, what each service does, and how they fit together.

The Infrastructure Layer

Before diving into individual services, here’s the stack:

  • Hardware: Raspberry Pi 4 (aarch64), Debian 13 (trixie)
  • Reverse proxy: nginx (ports 80/443)
  • SSL: Let’s Encrypt certificates via Certbot
  • Process management: PM2 (for most Node.js and Python backends)
  • Systemd: pm2-pi.service resurrects PM2 on boot; user services handle Hermes gateway, mpris-proxy, and OpenClaw

1. drone.jasonwang.us — VTOL Drone Simulator

Service: React + Vite + Three.js + Rapier physics
Port: 5173 (dev server), static dist/ for production
Purpose: A VTOL drone flight simulation with real-time physics, PID/LQR/MPC/SMC/Adaptive controllers, HUD visualization, and state management via Zustand.

This is an interactive 3D simulation for testing drone control algorithms. It runs a Vite dev server for development and serves a static production build. The project includes a modular controller system with abstract ControllerBase + Factory + Manager pattern.

Visit drone.jasonwang.us

2. aura.jasonwang.us — HealthCoach AI

Service: Node.js HealthCoach server
Port: 3047
Purpose: AI-powered health coaching with exercise tracking, chat, and goal management. Uses OpenRouter for free-tier LLM access (falling back to nvidia/nemotron-3.5-super-vl:free and google/gemma-4-26b-a4b-it:free).

The frontend is a React app served as static files, with API calls proxied to the Node.js backend at /api/. It includes authentication, push notifications, exercise logging, and AI-generated workout summaries.

Visit aura.jasonwang.us

3. apiaura.jasonwang.us — HealthCoach API

Service: Node.js HealthCoach server
Port: 3047
Purpose: Dedicated API subdomain for the HealthCoach backend, proxying to the same Node.js server as aura.jasonwang.us.

This provides a clean API endpoint for programmatic access to the HealthCoach service, separate from the frontend-facing aura.jasonwang.us.

Visit apiaura.jasonwang.us

4. zhuyin.jasonwang.us — Zhuyin Trainer

Service: Node.js server
Port: 3001
Purpose: A Zhuyin (Bopomofo) phonetic symbol trainer for learning Mandarin Chinese pronunciation. Includes a Next.js /reader proxy on port 3789.

This project helps with learning Zhuyin, the phonetic system used in Taiwan for Mandarin. The API backend handles data and user progress.

Visit zhuyin.jasonwang.us

5. mapscout.jasonwang.us — Map Scout AI Tour Guide

Service: Python FastAPI + React frontend
Port: 9813
Purpose: An AI-powered tour guide that explores maps and landmarks using LLM-powered narrative generation.

Map Scout combines map data with AI to create immersive walking tours. It suggests points of interest, weaves local history into narratives, and provides multi-sensory interaction guidance.

Visit mapscout.jasonwang.us

6. niche.jasonwang.us — NicheApp (Research Paper Tracker)

Service: Python FastAPI backend + wiki_stream frontend
Port: 8000
Purpose: Tracks research papers from arXiv and bioRxiv, with a MediaWiki-style interface for organizing and annotating academic literature.

This is a personal research database that ingests new papers, extracts key information, and lets you build causal graphs and evidence maps around research topics.

Visit niche.jasonwang.us

7. future.jasonwang.us — Possible Nodes

Service: Python FastAPI backend
Port: 8080
Purpose: A DAG-based causal reasoning system for exploring possible futures and decision trees.

Possible Nodes is a project for modeling causal relationships and exploring “what if” scenarios. It uses a directed acyclic graph structure to represent causal links between events and decisions.

Visit future.jasonwang.us

8. playlist.jasonwang.us — ActivityPlaylist

Service: Python FastAPI backend + React frontend
Port: 9427
Purpose: Activity tracking and playlist management for exercise and personal data logging.

This service tracks physical activities and creates playlists based on your data. It’s part of a broader personal data ecosystem.

Visit playlist.jasonwang.us

9. blogger.jasonwang.us — Egresspathy Blog Admin

Service: FastAPI admin interface
Port: 8001
Purpose: The admin interface for this very blog. It manages Pelican blog content (Markdown files), handles authentication, and triggers builds and pushes to GitHub.

This is where I write, edit, and publish blog posts. It’s a password-protected admin UI that talks to the Pelican static site generator and GitHub for deployment.

Visit blogger.jasonwang.us

10. hypescore.jasonwang.us — HypeScore

Service: Static React app (Vite)
Purpose: A static web application served as pre-built HTML/JS/WASM files.

HypeScore is a client-side application with broad MIME type support including WebAssembly. No backend — just static assets served efficiently by nginx.

Visit hypescore.jasonwang.us

All of these run on a single Raspberry Pi 4 behind nginx, with SSL certificates managed by Certbot. It’s a small but capable home lab that serves as both a personal utility suite and a playground for experimenting with AI, data, and web technologies.

This post documents the server infrastructure as of October 2026. Some services may have evolved since then.
