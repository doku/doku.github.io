Finally Learn Mandarin Pronunciation Without Pinyin Confusion

URL: https://zhuyin.jasonwang.us
Stack: Node.js, Next.js, vanilla JavaScript

What It Is

Pinyin lies to you. It uses familiar English letters, so your brain reads them like English. “q” isn’t “q.” “x” isn’t “x.” You think you’re saying it right, and native speakers hear something completely different. This trainer uses Zhuyin (Bopomofo) — the phonetic system Taiwan actually uses to teach kids — so you learn the sounds exactly as they are, with no bad habits.

What It Does

  • Learn Zhuyin symbols — a complete set of phonetic characters that don’t pretend to be English
  • Hear the sounds — audio for every symbol so you know exactly how to pronounce it
  • Practice until it sticks — drill until your mouth knows what to do
  • Reader mode — see Zhuyin layered over real Mandarin text and read it out loud

How It Works

You start with the symbols, hear how each one sounds, and practice until you can read Mandarin text with Zhuyin annotations. No false cognates, no English letter tricks — just the sounds, exactly as they are.

Tech Stack

Layer Technology
Backend Node.js
Reader Next.js
Frontend Vanilla JavaScript
Reverse proxy nginx
