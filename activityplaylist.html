Your Workouts, Actually Organized

URL: https://playlist.jasonwang.us
Stack: Python FastAPI, React

What It Is

Your exercise history is probably scattered across notes apps, photos, and your memory. “What did I bench last month?” “How many miles did I run in July?” You have to dig. Not anymore. This is one place for every workout, every set, every rep.

What It Does

  • Log every workout — open it, record what you did, it’s saved forever
  • See your history — every set, every rep, every weight, in one place
  • Track progress — when you want to know if you’re actually getting stronger, the numbers are right there
  • Build from where you are — log today’s workout and keep going

How It Works

You open the app, log what you did today, and it’s stored. No scattered notes, no forgotten workouts, no digging through photos. When you want to compare last month to this month, the data is right there.

Tech Stack

Layer Technology
Backend Python FastAPI
Frontend React
Reverse proxy nginx
Process manager PM2
